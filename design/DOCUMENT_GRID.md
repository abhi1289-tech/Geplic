# Geplic Document Grid

## Purpose

The document grid defines compact, predictable agreement geometry.

## Rules

- Use a constrained document width.
- Keep document content readable.
- Prefer two-column structures where information is naturally paired.
- Party A / Party B are side-by-side on desktop.
- Agreement detail fields use a compact grid.
- Responsive layouts collapse to one column when necessary.
- Print layouts must remain stable.

The grid is a document concern and must not leak into Dashboard or Create Agreement.
