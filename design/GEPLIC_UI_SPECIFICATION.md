# Geplic UI Specification

## Visual direction

Geplic uses a dark, polished application interface with:
- restrained surfaces
- strong typography
- subtle borders
- controlled gradients
- semantic status colors
- consistent rounded controls

## Common action language

| Action | Treatment |
|---|---|
| Primary | Brand |
| Secondary | Neutral/glass |
| Complete | Green semantic |
| Reject/Void | Restrained red semantic |

## Current Pact action refinement

Reject, Void, and Complete Agreement use restrained semantic surfaces instead of visually aggressive solid fills.

The confirmed Pact action radius is **20px**.

## Layout language

Spacing must be deliberate. Small spacing differences are considered visual inconsistencies because Geplic is intended to feel like one product.

## Document language

Agreement Builder and Agreement Print prioritize:
- compact information density
- aligned grids
- side-by-side parties
- consistent document width
- print quality
